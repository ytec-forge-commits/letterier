# レタリエ

便箋の上へ直接文章を書き、写真や署名を添えて、PDF・印刷まで仕上げるWindows用の手紙作成アプリです。[English](README.en.md)

対象はWindows 10/11 x64、WebView2 Runtimeが必要です。日本語の縦書き・横書きの手紙作成に用途を絞るため、利用者の指定によりUIは日本語のみです。手紙や画像はPC内で処理します。

## はじめ方

1. 「便箋を選ぶ」から和風10種・洋風10種を選びます。各デザインに縦横・1枚目・続き用の見た目があります。
2. 用紙をクリックして本文を入力します。用紙はA4、B5、はがき。本文が増えると次のページへ続きます。
3. 文字を選んでフォント・大きさ・太字等を変更します。写真・画像や文字箱は移動・拡縮・回転・透明度・前後関係・本文回り込みを調整できます。
4. 「ファイル → 名前を付けて保存」で `.binsen` を作成します。保存前からPC内に回復データを自動保存します。
5. 「PDF・印刷」でページを確認し、PDF保存またはWindowsプリンターへ出力します。印刷可能範囲からはみ出す場合は実寸・縮小・中止を選べます。

「ページの操作」で複製・順序変更・削除を確認して適用でき、1回の「元に戻す」で戻せます。「このページの見た目」で罫線や背景を調整します。「画面設定・使い方」の21テーマと大きい操作文字は印刷内容に影響しません。

印刷の初期設定は「紙面全体を印刷可能範囲へ縮小」です。プレビューの「印刷」は選択中の倍率と印刷できない余白を表示し、点線は出力しません。「実寸」を選ぶと、プリンターが印刷できない用紙端の飾りは切れます。「PDF（実寸）」のプレビューとPDF保存は、この縮小設定にかかわらず実寸です。

## 保存・回復

`.binsen` は現在の本文・書式・画像だけを含み、履歴は含みません。「保存履歴」で通常50件と保護版を管理し、プレビューから復元できます。復元前の状態も保護します。履歴ごと持ち運ぶには `.binsenbak` を書き出してください。「最近使った手紙」はPC内の回復データを開くため、元ファイルへの保存を続ける場合は「ファイルを開く」で選び直します。

自動保存はバックアップの代わりにはなりません。大切な手紙は名前を付けて保存し、別媒体へ履歴付きバックアップを残してください。保存に失敗した場合は画面に通知し、終了を止めます。別の場所へ保存してから終了してください。

Ctrl+S 保存 / Ctrl+Shift+S 名前を付けて保存 / Ctrl+Z 元に戻す / Ctrl+Y やり直す / Ctrl+Enter 改ページ。本文をクリックしてCtrl+Aで本文を全選択します。

## 素材と文字

手書き風20書体を同梱します。Windowsのインストール済みフォントも利用でき、不足フォントは代替表示しながら元の指定を保持します。JPEG・PNG等のほか、静的SVG、GIF/WebPのコマ選択、PSD統合画像、PDF互換AI/PDFのページ選択、OSコーデック対応時のHEICを扱います。詳細・上限・品質の違いは[画像形式](IMAGE-FORMATS.md)を参照してください。

本文・罫線・便箋装飾・静的SVGはベクターPDF出力です。PDF互換素材は画像へ変換します。Word形式、PSDレイヤー編集、クラウド同期、スマートフォン版は対象外です。

## 開発・検証・配布

Node.js 22以上、Rust 1.93.1で検証。WindowsのC++ビルドツール・SDKが必要です。

```powershell
npm ci
npm test
npm run check
npm run test:native
npm run build:native
```

フロントエンド生成先は `.local/frontend`、ネイティブ生成先は `.local/cargo-target` です。開発起動は `npm run tauri -- dev`。ブラウザー試験は `tests/browser/` のPlaywright CLIスクリプトを使用します。ブラウザーの保存先は検証用IndexedDBで、Windows版と共有しません。

ライセンス生成は `python scripts/collect-licenses.py`、フォント・PDF資源の取得は `scripts/acquire-fonts.py` と `scripts/acquire-pdf-assets.py`。通常ビルドは同梱済み資源を使います。[配布手順](distribution/README.md)にStore版と直接配布版の準備・署名境界を記載しています。現時点はユーザー確認用で、GitHub・Forge・Storeへ公開していません。
