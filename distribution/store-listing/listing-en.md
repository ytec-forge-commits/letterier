# Microsoft Store listing (English)

## Product name

Letterier

## Short description

Choose stationery, write a vertical or horizontal letter, add photos and text boxes, then export PDF or print from Windows.

## Description

Letterier is a local Windows app for writing directly on stationery and adding photos, illustrations, signatures, and independent text boxes.

Choose from ten Japanese-inspired and ten Western-inspired stationery designs. Letterier supports Japanese vertical and horizontal writing, English horizontal writing, and A4, B5, or postcard paper. Longer text flows naturally to following pages, while images and text boxes can move between pages.

Set a default font before writing, format a selection, or apply the chosen font to one page or the whole letter. When the letter is ready, save it as PDF or review the print preview and send it to a Windows printer.

Letterier has no account, advertising, analytics, or cloud sync. Documents, images, history, and preferences are processed on this PC. Larger control text, 21 interface color themes, and illustrated Japanese and English manuals help make the app approachable for first-time users.

## Features

- Japanese vertical and horizontal writing, plus English horizontal writing
- Ten Japanese-inspired and ten Western-inspired stationery designs
- A4, B5, and postcard paper
- Photos, images, signatures, and movable text boxes
- Default fonts, selection formatting, and page-wide or document-wide formatting
- Local autosave, version history, and history-aware backups
- PDF export with vector text and native Windows printing
- Japanese and English interface, 21 color themes, and larger controls
- No account, no ads, and no internet required for normal use

## What's new

Version 2.0.0 adds reusable personal stationery, drag-to-position backgrounds, a target line-length setting, and font-size-aware automatic rules. Adjust character spacing and the default body size, use the bottom-right zoom slider, recognize Save by its floppy-disk icon, and find clearer paragraph controls. Dismissible screens close on outside clicks, and the output dialog prioritizes printing. The next launch restores the saved window size. Japanese and English manuals have been updated.
