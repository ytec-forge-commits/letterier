# Microsoft Store 掲載文（日本語）

## 製品名

レタリエ

## 短い説明

便箋を選び、縦書き・横書きの手紙へ写真や文字箱を添えて、PDF保存や印刷まで仕上げられるWindowsアプリです。

## 説明

レタリエは、便箋の上へ直接文章を書き、写真・イラスト・署名・文字箱を自由に添えられるWindows用の手紙作成アプリです。

和風10種・洋風10種の便箋を収録。日本語の縦書きと横書き、英語の横書きに対応し、A4・B5・はがきから用紙を選べます。本文が増えると次のページへ自然に続き、画像や文字箱はページをまたいで移動できます。

標準フォントを指定してから書き始めることも、選択範囲・指定ページ・全ページの書体を後から整えることもできます。完成した手紙はPDFへ保存するか、印刷プレビューを確認してWindowsのプリンターへ出力できます。

アカウント、広告、アクセス解析、クラウド同期はありません。手紙・画像・履歴・設定はこのPC内で処理します。大きめの操作文字や21種類の画面配色も用意し、初めての方にも迷いにくい操作を目指しています。

## 主な機能

- 日本語の縦書き・横書きと英語の横書き
- 和風10種・洋風10種の便箋
- A4・B5・はがき対応
- 写真・画像・署名・文字箱の配置とページ間移動
- 標準フォント、部分書式、ページ単位・全ページの一括書式
- 自動保存、保存履歴、履歴付きバックアップ
- ベクター文字を保つPDF保存とWindows印刷
- 日本語・英語UI、21種類の画面配色、大きい操作文字
- アカウント不要、広告なし、通常利用はオフライン

## このバージョンの新機能

レタリエ 1.0.4 初回Store版です。日英UI、縦書き・横書き、20種の便箋、画像と文字箱のページ間移動、保存履歴、PDF・印刷、分かりやすい日英マニュアルを収録しています。

## スクリーンショット説明

1. 20種類の便箋から、手紙に合うデザインを選べます。
2. 横書きの本文を便箋へ直接入力できます。
3. 日本語の縦書きで、レタリエらしい手紙を作れます。
4. 本文とは独立した縦書き・横書きの文字箱を配置できます。
