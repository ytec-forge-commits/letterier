レタリエ 1.0.4 利用者向け説明書
================================

1. ソフトの概要
---------------
レタリエは、便箋を選び、縦書き・横書きで文章を書き、写真や文字箱を添えて、
PDF保存や印刷まで行えるWindows用の手紙作成アプリです。
手紙と画像は通常、お使いのパソコン内だけで処理します。

2. 作者と連絡先

作者: Y-TEC
作者への連絡先: Y-TEC Forge お問い合わせ
https://ytec.cloudfree.jp/forge/contact/

不具合については、レタリエのバージョン、行った操作、期待した結果、
実際の結果を記載してください。手紙本文や個人情報を含む画像は、
調査に必要な場合を除いて送信しないでください。

4. 動作環境
-----------
- Windows 10・11（64ビット）
- Microsoft WebView2 Runtime

ポータブルZIP版にWebView2 Runtimeは同梱していません。
未導入の場合は、Microsoft公式のWebView2 Runtimeを導入してください。
通常インストーラー版は、未導入時だけMicrosoftからRuntimeを取得します。

5. インストールと起動
---------------------
【ポータブルZIP版】
1) ZIPを任意のフォルダーへ展開します。
2) 展開したフォルダー内の Letterier.exe を起動します。
3) 自己署名版のためWindowsの警告が表示された場合は、配布元とファイル名を
   確認してから起動してください。

【通常インストーラー版】
1) Letterier-1.0.4-windows-x64-self-signed-setup.exe を実行します。
2) 画面の案内に従ってインストールします。
3) スタートメニューなどから「レタリエ」を起動します。

【Microsoft Store版】
Microsoft Storeのレタリエページで「インストール」を選びます。

6. アンインストール
-------------------
【ポータブルZIP版】
レタリエを終了し、展開したフォルダーを削除します。

【通常インストーラー版／Microsoft Store版】
Windowsの「設定 → アプリ → インストールされているアプリ」を開き、
「レタリエ」のメニューから「アンインストール」を選びます。

利用者が保存した .binsen、.binsenbak、PDF、画像は自動では削除されません。
必要なファイルを確認してから、不要なものだけを利用者自身で削除してください。
