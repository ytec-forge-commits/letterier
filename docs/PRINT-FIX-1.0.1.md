# 1.0.1 縦書き・印刷修正の確認記録

2026-09-06。利用者から提供された画面、A4印刷スキャン、`.binsen`文書を読み取り専用で調査した。印刷は「紙面全体を印刷可能範囲へ縮小」で行われ、実寸では上端が一部切れたとの追加報告があった。文書の本文・画像をテスト資源へ流用せず、同じ月とすすき・A4・縦書き設定の合成文書で検証した。

## 修正

- 空の紙面の「ここから、お手紙を。」は、組版結果の最初の本文行/列に合わせて表示する。縦書きは右上から縦表示、横書きは左上から横表示。入力後は非表示になる。
- 操作画面の背景色`#edece6`が印刷時にもルート背景に残っていた。縮小後に露出する余白へ混入させないよう、印刷キャンバスと用紙外の背景を白にする。便箋自体の淡い紙色は維持する。
- プリンターへの印刷は「縮小」を初期選択にする。印刷プレビューへ同じ倍率/移動量と、プリンターが返す印刷不可領域を反映する。範囲を示す点線はプレビュー限定で、出力には含めない。
- 実寸印刷は100%を維持し、用紙端が切れる理由を表示する。PDFプレビューとPDF出力も実寸を維持し、印刷用の縮小を混入させない。
- 修正版を識別できるよう版番号を1.0.1に更新。配布準備時に古いNSIS版が混ざらないよう、対象版のファイルだけを選択する。

保存形式、本文・画像データ、依存ライブラリ、Rustのプリンター処理は変更していない。Director本体の課題対応は別タスクに委ね、本プロジェクトから変更していない。
