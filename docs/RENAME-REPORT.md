# 正式名称「レタリエ」への変更

2026-09-06の名称変更指示を反映。旧開発名は「便箋工房」。正式名称は「レタリエ」、説明表記は「レタリエ — 手紙・便箋作成アプリ」。Letter + Atelier、「一通の手紙をつくる、小さなアトリエ」の意味を持つ。

## 変更対象の分類と実施

検索対象はプロジェクトのソース、設定、テスト、文書。生成済みの過去の検証証跡は名称検索による書き換え対象にしない。

| 分類 | 対象 | 対応 |
|---|---|---|
| 製品名 | HTMLタイトル、編集画面のブランド表示、ネイティブのウィンドウタイトル、技術試作画面 | レタリエへ変更 |
| 利用者向け文言 | 非対応形式の案内、起動失敗の案内、保存ダイアログのフィルター、ファイル関連付け表示 | レタリエへ変更 |
| メタデータ | npm description、Cargo description、Tauri productName | 正式名称と説明表記を反映 |
| 配布物 | Tauri mainBinaryName | `レタリエ`を指定。Tauriの配布ビルド時の実行ファイルは`レタリエ.exe` |
| 文書 | プロジェクトAGENTS、開発仕様書 | 正式名称を反映。Downloadsの原本は保持し、更新版はSPECIFICATION.md |
| 履歴 | NAME-CHECK.md | 旧名称の調査であることを明記し、検索語と第三者名は保持 |

## 維持した内部識別子

- Tauri identifier: `jp.ytec.binsen-kobo`（変更なし）。これに基づくWindows AppDataの保存先を変更しない。
- 文書形式 `binsen` / version 1、拡張子`.binsen`、履歴バックアップ`.binsenbak`（変更なし）。
- ブラウザ検証用IndexedDB: `binsen-kobo-local-v1`（変更なし）。
- 自動保存・履歴・設定・テンプレートの保存キー（名称変更による変更なし）。
- npm/Cargoの内部パッケージ名`binsen-kobo`、各lockfile、開発フォルダー`business-apps/binsen-kobo`（変更なし）。これらは公開表示名ではない。Cargo単体の中間ビルド名と、Tauriの配布実行ファイル名を区別する。
- 既存レジストリへ直接変更する処理・保存データの移行処理は追加していない。本アプリの初回公開前の変更であり、旧製品名の公開済みインストーラーはない。

## 検証

- PASS: フロントエンドの型検査とビルド。
- PASS: Windowsネイティブのdebugビルド。
- PASS: ブラウザ起動時のタイトル・ヘッダーが「レタリエ」。名称変更前の回復用データから本文・画像・文字箱・罫線設定が回復。
- 保存形式の往復、履歴復元、自動保存の順序等は既存回帰テストで確認。ネイティブの保存ダイアログ、実ファイル往復、終了前保存はアプリ全体の最終検証で追記する。
- 外観テーマ・ユーザーテンプレート設定は名称変更時点で実装中。完成後の保持確認を最終検証に含める。

## 旧名称の残存一覧

意図して保持: NAME-CHECK.mdの検索語・第三者サービス名、SPECIFICATION.mdの旧開発名と原仕様の参照ファイル名、本レポートの変更履歴。旧名由来の内部識別子は上記の通り。依存物・キャッシュ・過去の検証成果物は検索置換していない。

## 配布時の確認

NSISの製品表示はTauri productNameを使用する。最終インストーラー・実行ファイルのファイル名とWindowsプロパティを配布ビルド後に確認する。Microsoft StoreのDisplayName、説明、スクリーンショット、公開用README、Forge/GitHubの公開表記も「レタリエ」で統一する。正式なStore Identity/Publisherはユーザー確認後に関連付ける。

名称変更を理由に、和風・洋風の20便箋、21外観テーマ、アイコンコンセプト、保存方式、機能要件は変更していない。
